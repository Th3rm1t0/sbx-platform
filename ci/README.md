# ci

CI の中身を置く。ワークフロー（`.github/workflows/`）は「いつ、どの順で何を呼ぶか」だけを書き、判断はここに置く。

| 置き場所 | 中身 |
|---|---|
| `policy.yaml` | 信頼する取得元、ライセンスの許可、危険度のルール、保留の期限 |
| `scripts/` | 取り込み、危険度の判定、kit の同梱設定の生成 |
| `prompts/` | AI レビューへの指示文 |
| `tests/` | スクリプトのテストと、危険度判定の試験用の差分 |

このディレクトリを変える PR は CODEOWNERS の承認が必要。
